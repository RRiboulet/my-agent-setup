# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Lesson knowledge comes from here, not from memory; wisdom comes from the communities listed here.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.

## Gaps

- Nothing trustworthy on deload frequency. Find one before teaching that lesson.

## Preferences

- User does not want to join online communities; local classes only.
```

## Rules

- **High-trust only.** Primary sources, recognised experts, peer-reviewed work, and communities with strong moderation. Marketing dressed as education stays out.
- **Annotate every entry.** A bare link is useless in three months: one line on what it covers and when to reach for it.
- **Group by knowledge and wisdom**, mirroring the philosophy in `SKILL.md`. A resource can appear in only one group.
- **Surface gaps explicitly.** If the mission needs an area with no good source, say so in `Gaps` rather than filling it from memory. A named gap is what the next search is for.
- **Prune ruthlessly.** A source that turned out to be wrong, shallow, or off-mission is removed, not buried. Five sharp sources beat thirty mediocre ones.
- **Record community preferences.** If the user has opted out of joining communities, note it so no later session keeps proposing them.
- **Record what you actually read.** A source listed here is one you are teaching from; a promising link you have not opened belongs in `Gaps`.
